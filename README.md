# Secure AI-Based Video Player

This project is a secure AI-powered video player with:
- User authentication
- Face recognition login
- Voice-controlled video playback

## Technologies
- Flask (Backend)
- OpenCV (Face Recognition)
- JavaScript (Frontend & Voice Commands)
- SQLite (Database)

## Features
- Secure login with face verification
- AI voice assistant for video control
- Modular professional architecture

## How to Run
1. Start backend: `python app.py`
2. Open frontend using Live Server
3. Register → Register Face → Login → Control video by voice
